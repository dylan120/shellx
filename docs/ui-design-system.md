# ShellX UI 设计基线

## 页面类型

ShellX 是 macOS 工具型工作台应用，主要页面类型包括：

- 会话管理分栏页：左侧会话树，右侧会话详情或终端工作区。
- 终端工作台：顶部标签栏、中间 xterm.js 终端、底部状态与传输信息栏。
- 脚本管理分栏页：左侧脚本列表，右侧脚本编辑区。
- 批量执行页：上方执行配置，左侧目标选择，右侧执行结果与输出。
- 配置页和编辑弹窗：分组表单，用于维护偏好和对象属性。

## 设计入口

当前实现为 Electron/TypeScript，设计 Source of Truth 是：

- `electron-shellx/src/renderer/styles.css`
- `electron-shellx/src/renderer/main.ts` 中的通用渲染 helper，例如 `button`、`field`、`settingsSection`、`statusPill`、`emptyState`
- 现有 CSS 变量、分组面板、状态胶囊、标签、空态和表单样式

不要重新引入旧 Swift 设计系统或 AppKit/SwiftUI 组件。

## 视觉 Token

共享视觉 token 集中在 `:root` 和主题变量中：

- `--bg` / `--panel` / `--panel-2`：页面、侧栏、分组和输入表面。
- `--text` / `--muted` / `--subtle`：正文、辅助文本和弱说明。
- `--stroke` / `--stroke-strong`：分隔线和容器边界。
- `--accent` / `--accent-2`：主操作和选中强调。
- `--terminal` / `--terminal-panel`：终端内容和状态栏背景。
- `--danger` / `--warning` / `--success`：真实错误、警告和成功状态。

圆角维持当前产品基线：分组面板 8px，控件 6px。边框颜色层级最多保持三类：普通分隔、容器边界、强调边界；默认不使用投影，用背景密度、间距和 1px 边界表达层级。

## 页面基线

- 主工作台使用清晰的三层层级：导航、主要内容、辅助状态。
- 页面背景保持安静，内容分组使用轻量边界和留白。
- 主操作使用 `primary` 按钮，次要操作使用 `secondary`，危险操作使用 `danger`。
- 状态使用胶囊标签表达，颜色只用于认证、连接、执行结果、错误等真实状态。
- 侧栏、终端底栏、标签文本、配置说明、空态说明和状态摘要必须保证对比度。
- 编辑和配置继续使用弹窗或分组表单，不在列表行内展开复杂编辑。
- 不要使用营销页式大 Hero、装饰渐变球或过度卡片化布局；ShellX 是重复使用的运维工具。

## 状态覆盖

新页面或改版页面需要至少覆盖：

- 空态：使用现有 `emptyState` 样式。
- 错误态：展示可复制或可诊断的错误信息。
- 禁用态：运行中、无选择、无有效输入时禁用按钮。
- 加载/运行态：使用状态胶囊或进度组件。
- 选中态：复用现有 `.active` / `.selected` / `--accent` 语义，不重新定义一套颜色。

## 响应式与可访问性

- 主窗口最小宽度按 1080px 设计。
- 脚本管理最小宽度按 860px 设计。
- 批量执行最小宽度按 980px 设计。
- 图标按钮必须有明确文本或 `title` / 可访问名称。
- 正文和状态文本避免覆盖关键操作；长状态应单行截断，完整内容放在详情或输出区。
- 固定格式控件如标签栏、终端面板、工具栏和底栏必须有稳定尺寸，避免 hover、状态变化或动态文案导致布局跳动。
